Snake animation and 3D contribution graph.
Add these after you have 1-2 months of regular commits:
1. Create the folder .github/workflows in your profile repo and copy snake.yml and 3d-contrib.yml into it.
2. Settings > Actions > General > Workflow permissions > Read and write.
3. Actions tab > run each workflow once.
4. Add these two lines to README.md where you want them:
